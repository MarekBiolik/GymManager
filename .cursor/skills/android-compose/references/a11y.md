# Android accessibility (trimmed)

Cross-platform floor: `ui-ux` skill + Fitness/Gym contrast targets (≥ 4.5:1 body text).

## Prefer

- `contentDescription` / semantics for icon-only controls
- Touch targets ≥ 48dp where practical
- Do not use color alone for state — pair with text/icon
- Honour system font scale; avoid fixed tiny text for critical actions

## Tokens

Semantic text/surface colors from generated theme should already target AA on OLED dark. If a one-off color fails contrast, fix the **token** (via `design-tokens`), not a local hardcode.
